# Devil x Slime Wiki

The wiki for **Devil x Slime**, the High School DxD addon for Tensura: Reincarnated.

Read it at **https://malwikpl.github.io/devil-x-slime-wiki/**.

## Editing

Every page is a Markdown file in `docs/`. Edit one on GitHub (the pencil on any wiki page links here), commit to `main`,
and the site rebuilds itself in about a minute.

- Page order and titles: `nav` in `mkdocs.yml`.
- Pictures: `docs/assets/images/`.
- Colours: `docs/assets/stylesheets/extra.css`.

To preview locally:

```sh
pip install -r requirements.txt
mkdocs serve
```

then open http://127.0.0.1:8000.

The mod's source is not in this repository.
